# 🚀 SIAP - Sistem Informasi Administrasi Pelajar

SIAP adalah solusi digital untuk manajemen pendataan siswa yang menggabungkan fungsionalitas sistem informasi dengan desain UI/UX yang eye-catching. Aplikasi ini memungkinkan admin sekolah untuk mengelola identitas, data akademik, hingga informasi kontak siswa secara terpusat dan aman.  

## ✨ Fitur Utama:Modern & Responsive UI: 
* Menggunakan tema gelap dengan efek glassmorphism yang elegan dan ramah di berbagai perangkat.  
* Secure Admin Portal: Dilengkapi dengan sistem otentikasi login untuk menjaga keamanan data.  
* Integrated Data Validation: Validasi input otomatis untuk memastikan data yang disimpan akurat dan lengkap.  
* Fluid User Experience: Notifikasi interaktif menggunakan SweetAlert2 untuk umpan balik pengguna yang lebih baik.  

## 🛠️ Teknologi yang Digunakan:
* Frontend: HTML5, CSS3 (Modern Flexbox & Grid), Google Fonts.  
* Logic: Vanilla JavaScript (Factory Functions & Event Handling).  
* Library: SweetAlert2 untuk modal notifikasi yang profesional.  Icons: Font Awesome 6.
